# Downloads

Download the latest release binaries from GitHub Releases.

- GitHub releases page: [https://github.com/spetix/bar-out-adapters/releases](https://github.com/spetix/bar-out-adapters/releases)
- Latest release: [https://github.com/spetix/bar-out-adapters/releases/latest](https://github.com/spetix/bar-out-adapters/releases/latest)

## Direct asset URLs

Use the tag name in the URL path to download a specific release asset:

- `https://github.com/spetix/bar-out-adapters/releases/download/<tag>/bar-out-adapters-linux-amd64`
- `https://github.com/spetix/bar-out-adapters/releases/download/<tag>/bar-out-adapters-linux-arm64`

When a tagged release is published, the GitHub workflow attaches the built binaries to the release assets.

If you want a specific tag, replace `<tag>` with the release tag (for example `v1.0.0`).
